## ①③④ 创意功能实现方案（本轮）
- 用户问「技能自生长 / 旅行手账绘本 / 记忆星图」怎么具体实现，产出 `docs/创意功能实现方案-技能自生长-手账绘本-记忆星图.md`（v1.0）。
- 代码摸底关键发现：
  - `DynamicSkillLoader.JsonSkillProvider.load()` 是 TODO 桩返回空 List，`POST /api/skills/load/json` 实际加载 0 个——技能自生长第 1 步要先补齐它。
  - `SemanticTriggerPolicy` 只在启动时（Order 1）为 skills.yml 技能算嵌入缓存，运行期注册的动态技能永远匹配不到语义路由 → 需加 `registerDynamicSkill()`。
  - `SystemPromptBuilder.loadSkillPrompt()` 只读 classpath → 动态技能提示词用 `inline:` 前缀约定绕开。
  - `FileGenerationService.generatePdf()` 是 PDFBox 手工排版纯文本，不支持插图；手账绘本需新建 `TravelJournalRenderer`（PDImageXObject 插图，A5 竖版）。
  - `TravelPlanOption` 已有 `itineraryItems` 结构化逐项数据（删看板时保留的）；需给 TravelPlanService 补 `getSelectedPlan(userId)` 读取口。
  - 记忆星图：`MemoryStore.getAll()` 不返回向量，需给 `QdrantMemoryStore` 加 scrollWithVectors；降维用自写 PCA（≤几百点）；复用 vector-visualization.html 做 Tab。
- 建议实施顺序：④记忆星图（风险最低）→ ①技能自生长（叙事最强）→ ③手账绘本（演示最好但依赖出图耗时）。
